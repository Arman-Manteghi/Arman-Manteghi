**[Shadowlight](https://github.com/Arman-Manteghi/shadowlight)**
&nbsp;·&nbsp; exposure scanner for self-hosted AI services

A read-only command-line scanner that finds AI services answering without authentication: model servers, vector databases, AI web UIs and MLOps tools.
It fingerprints 23 services, judges whether each one is actually exposed, scores the risk, matches known advisories by version, and writes JSON, CSV or HTML reports with CI-friendly exit codes.
